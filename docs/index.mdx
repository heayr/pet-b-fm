# balakovo-fm

**Фриланс-платформа** с админ-панелью, авторизацией (NextAuth v5 + 2FA) и управлением контентом.

## Стек

- **Next.js 15** (App Router)
- **React 19** (Server Components)
- **TypeScript 5**
- **Prisma** (PostgreSQL)
- **NextAuth v5** (JWT-сессии, 2FA)
- **Tailwind CSS 3**
- **Zod** (валидация)
- **React Hook Form** (формы)

## Быстрый старт

```bash
npm install
npm run prisma:generate
npm run prisma:migrate
npm run dev
```
